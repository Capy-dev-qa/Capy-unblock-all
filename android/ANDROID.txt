Отдельное Android-приложение: гонка obfs4-мостов для Tor VPN (Play Market: org.torproject.vpn) и Orbot.

Tor VPN не принимает мосты из чужого приложения — только вставка в UI.
Эта программа: гоняет TCP до мостов → копирует победителя → открывает Tor VPN.

Сборка (Android Studio):
1. File → Open → папка android/
2. Дождись Gradle Sync
3. Run на телефоне (USB debugging)

Или из каталога android/:
  ./gradlew :app:assembleDebug
APK: android/app/build/outputs/apk/debug/app-debug.apk

В приложении:
- Подобрать мост
- В Tor VPN  (буфер + открыть org.torproject.vpn)
- В Orbot     (буфер + старт Orbot)

В Tor VPN после открытия:
  Connection → Bridges → Use a bridge → Add new bridges → вставь → Save

Свои мосты: android/app/src/main/assets/bridges.txt
Формат как в torrc:
  Bridge obfs4 IP:PORT FINGERPRINT cert=… iat-mode=0
